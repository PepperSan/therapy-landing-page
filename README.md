# Therapy Landing Page

A clean and responsive landing page concept for therapy, psychology, coaching, or private practice services.

## Live Demo

After enabling GitHub Pages, the live project will be available here:


## About the Project

This project is a portfolio demo that shows a simple landing page structure for a service-based business.

The page includes:

- Hero section
- About section
- Services section
- Consultation process section
- Pricing block
- Contact form
- Responsive layout for mobile devices

## Technologies Used

- Responsive design
- GitHub Pages
